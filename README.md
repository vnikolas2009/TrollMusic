# TrollMusic

Локальный музыкальный плеер для iOS и Android на Flutter. Медиатека строится из ваших файлов: никаких аккаунтов, токенов, подписок и бэкенда. Особенность приложения — экран текстов песен с синхронизацией и подсветкой по словам (enhanced LRC).

Английская версия: [README_EN.md](README_EN.md). Устройство проекта: [ARCHITECTURE.md](ARCHITECTURE.md).

## Возможности

### Медиатека
- Импорт файлов (MP3, M4A, FLAC, WAV, OGG, Opus, AAC, WMA, ALAC, AIFF) и сканирование папок: быстрое (только изменённые) и полное.
- Теги, обложки и встроенные тексты читаются из файлов. Без тегов исполнитель и название берутся из имени файла («Артист - Название.mp3»).
- Вкладки: все треки, плейлисты, исполнители, альбомы, избранное. Сортировка (недавние, название, исполнитель, альбом, длительность, часто слушаемые), фильтр «только без текста».
- Поиск по названию, исполнителю, альбому и по строчке из текста песни.
- Плейлисты: создание, добавление треков, перестановка, переименование. Меню трека: играть следующим, в очередь, избранное, теги и обложка, удаление.
- Резервная копия медиатеки в JSON.
- Поиск треков в интернете: вкладка «Импорт» → встроенный браузер. Когда на странице начинает играть аудио или открывается прямая ссылка на файл, приложение предлагает скачать его в медиатеку. Потоки без прямого файла (YouTube, Spotify и т. п.) скачать нельзя.

### Плеер
- Очередь с перестановкой, повтор, скорость 0.5–2×, кроссфейд, пропуск тишины (Android), таймер сна по минутам или «до конца трека».
- Перемешивание: кнопка «вперемешку» умеет **умный** порядок: недавно игравшие треки уходят ближе к концу, редко слушаемые чаще оказываются впереди, треки одного исполнителя по возможности не идут подряд (можно выключить в настройках).
- Восстановление сессии: после перезапуска возвращаются очередь, текущий трек и позиция в нём. Позиция сохраняется при паузе, смене трека и когда приложение уходит в фон. Недоступные файлы из очереди пропускаются.
- Свайп по обложке и мини-плееру переключает треки, нажатие на время показывает оставшееся время, под обложкой видна текущая строка текста.
- Битый файл пропускается, очередь не останавливается. Медиа-уведомление и экран блокировки.

### Тексты песен
Текст подтягивается несколькими способами:
1. Файл `.lrc` / `.elrc` / `.txt` рядом с аудио или выбранный вместе с ним.
2. Пакетный импорт: файлы привязываются к трекам по имени аудиофайла, названию, «Артист - Название» и тегам `[ti:]`, `[ar:]`.
3. Теги файла (ID3/Vorbis).
4. Онлайн: LRCLIB, Kugou (пословные метки), QQ Music, Lyrics.ovh. Выбирается лучший кандидат по названию, исполнителю и длительности; приоритет у enhanced LRC, затем у LRC, затем у обычного текста. Тексты с замазанными словами уступают полным, а версия с сильно отличающейся длительностью показывается без таймкодов.
5. Вручную: вставка текста или загрузка файла.

На экране текста: подсветка по словам, три стиля (Spotify-подобный, минимальный, классический), размер текста, сдвиг синхронизации для каждого трека, нажатие на строку перематывает, долгое нажатие повторяет строку, фон из своей картинки или GIF с затемнением или градиентом. Все эти настройки находятся в листе «Аа» в шапке экрана.

**Перевод.** Кнопка перевода в шапке показывает под каждой строкой перевод на выбранный язык (12 языков). Оригинал, в том числе таймкоды и пословные метки enhanced LRC, не меняется: перевод хранится отдельно и привязан к строкам. Готовый перевод кэшируется на устройстве, повторно сеть не нужна; кэш обновляется, если текст песни изменился. Перевод использует бесплатную неофициальную точку Google Translate без ключа, поэтому она может измениться или быть недоступна.

### Оформление
- Темы (тёмная, светлая, системная, AMOLED), акцентный цвет, градиентный фон.
- Свои шрифты (TTF/OTF) и встроенные Inter и Manrope, четыре уровня толщины и размер текста интерфейса.
- Режимы анимаций (плавно, быстро, спокойно, минимум), уровень эффектов, форма обложек.

### Главная
Плашка со ссылкой на канал TrollCerts, «продолжить», подборка дня, недавно добавленное, недавно слушали, часто слушаете, карточка «без текста» и список плейлистов.

## Сборка

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Релизные сборки (Android APK, iOS IPA) запускаются вручную через workflow `.github/workflows/build_release.yml`.

Сеть нужна только для онлайн-поиска и перевода текстов, встроенного браузера и ссылки на канал; остальное работает без неё.
