# TrollMusic

Локальный музыкальный плеер (iOS / Android) на Flutter: тёмный минималистичный интерфейс, медиатека из ваших файлов, синхронизированные тексты песен, в том числе **enhanced LRC с подсветкой по словам**. Никаких стриминговых сервисов, аккаунтов и токенов.

## Возможности

### Медиатека
- Импорт файлов (MP3, M4A, FLAC, WAV, OGG, Opus, AAC, WMA, ALAC, AIFF) и сканирование папок, быстрое (только изменённые) и полное.
- Теги, обложки и встроенные тексты читаются из файлов; без тегов исполнитель и название берутся из имени файла («Артист - Название.mp3»).
- Вкладки: все треки, плейлисты, исполнители, альбомы, избранное. Сортировка (недавние, название, исполнитель, альбом, длительность, часто слушаемые), поиск, фильтр «только без текста».
- Плейлисты: создание, добавление, перестановка, переименование. Меню трека: играть следующим, в очередь, избранное, теги и обложка, удаление.
- Поиск по названию, исполнителю, альбому и **по строчке из текста песни**.
- Резервная копия медиатеки в JSON.

### Тексты песен
Текст подтягивается всеми способами сразу:
1. **Рядом с аудио:** файл `.lrc` / `.elrc` / `.txt` с тем же именем (при сканировании папки и при выборе файлов).
2. **Пакетный импорт:** можно отметить сразу аудио и `.lrc`, либо отдельно выбрать много `.lrc`. Файлы привязываются к трекам по имени аудиофайла, названию, «Артист - Название» и тегам `[ti:]`, `[ar:]`.
3. **Теги файла:** текст, встроенный в ID3/Vorbis.
4. **Онлайн, автоматически:** LRCLIB, Kugou (отдаёт пословные метки), QQ Music, Lyrics.ovh. Все источники опрашиваются параллельно. Запрос уточняется: чистятся номера треков, `feat.`, `Remastered`, скобки; берётся главный исполнитель; для безымянных файлов исполнитель извлекается из имени. Лучший кандидат выбирается по названию, исполнителю и длительности; приоритет у enhanced LRC, затем у LRC, затем у обычного текста. Тексты с замазанными звёздочками словами уступают полным, а если длительность версии отличается от трека больше чем на 5 с, таймкоды не используются и текст показывается без них.
5. **Вручную:** вставка текста или загрузка файла в карточке трека.

Пакетный поиск для всей медиатеки запускается кнопкой на главной, во вкладке «Импорт» и в настройках; для новых треков он стартует после импорта (можно отключить).

Поддерживается обычный LRC, enhanced LRC (`<мм:сс.хх>` перед словом), несколько меток на одной строке, `[offset:]`. На экране текста слово подсвечивается по мере звучания; сдвиг синхронизации настраивается для каждого трека.

### Плеер
- Очередь с перестановкой, перемешивание, повтор, скорость 0.5–2×, кроссфейд, пропуск тишины (Android).
- Таймер сна: по минутам или «до конца трека».
- Восстановление последнего трека и позиции, медиа-уведомление, обложки.
- Битый файл пропускается, очередь не останавливается.

### Главная
Продолжить, подборка дня, недавно добавленное, недавно слушали, часто слушаете, карточка «без текста».

## Сборка

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Релизные сборки (Android APK, iOS IPA) собирает workflow `.github/workflows/build_release.yml`.

Сеть нужна только для онлайн-поиска текстов; без неё приложение работает полностью.

Подробности устройства: [ARCHITECTURE.md](ARCHITECTURE.md).
