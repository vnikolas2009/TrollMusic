# Инструкции для Claude

Перед любой работой с кодом прочитай `ARCHITECTURE.md`: там карта файлов, DI, потоки данных, сеть и известные ограничения. Не обходи весь репозиторий заново, открывай только файлы, на которые указывает архитектура.

- Архитектура: Flutter-клиент + бесплатный Vercel-бэкенд `/api` (только метаданные Spotify). Аудио берётся напрямую: SoundCloud (MP3/HLS), фолбэк InnerTube (`ANDROID_VR`/`IOS`). Через Vercel аудио не проксировать.
- Все HTTP-запросы клиента идут через `createDio()` (DoH-резолвер).
- Проверка перед коммитом: `flutter pub get`, `flutter analyze`, `flutter test`. Flutter может не быть в PATH, тогда используй полный путь к `flutter.bat`/`flutter`.
- Позицию воспроизведения (`positionProvider`) слушай только в узких виджетах (`_SeekBar`, `_MiniProgress`), не в `build` экранов.
- Сетевые изображения: всегда `cacheWidth` (`AppConfig.coverCacheWidth` / `thumbCacheWidth`).
- Тяжёлый JSON разбирай через `parseJson` (`core/utils/json_isolate.dart`, `Isolate.run`).
- Пользователь пишет по-русски; строки интерфейса на русском.
- Чистую логику выноси в функции и покрывай тестом в `test/`. Существующие тесты не ломай.
- Коммиты в `main` запускают релизную сборку; сообщения в стиле `feat: ...`, `refactor: ...`, `fix: ...`.
- При изменении структуры, провайдеров, потока воспроизведения или сети обновляй `ARCHITECTURE.md` (и README, если меняются возможности).
