# Инструкции для Claude

Перед любой работой с кодом прочитай `ARCHITECTURE.md`: там карта файлов, данные и потоки. Не обходи весь репозиторий заново, открывай только файлы, на которые указывает архитектура.

- Приложение полностью локальное: никаких стриминговых сервисов, аккаунтов, токенов и бэкенда. Сеть только для поиска текстов (`core/network/lyrics`), запросы идут через `createDio()`.
- Проверка перед коммитом: `flutter pub get`, `flutter analyze`, `flutter test`. Flutter может не быть в PATH, тогда используй полный путь к `flutter.bat`/`flutter`.
- Позицию воспроизведения (`positionProvider`) слушай только в узких виджетах (`_SeekBar`, `_MiniProgress`), не в `build` экранов.
- Пользователь пишет по-русски; строки интерфейса на русском.
- Чистую логику выноси в функции и покрывай тестом в `test/`. Существующие тесты не ломай.
- Коммиты в `main`; сообщения в стиле `feat: ...`, `refactor: ...`, `fix: ...`.
- При изменении структуры, провайдеров, потока воспроизведения или импорта обновляй `ARCHITECTURE.md` (и README, если меняются возможности).
