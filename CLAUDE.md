# Инструкции для Claude

Перед любой работой с кодом прочитай `ARCHITECTURE.md` — там карта файлов, DI, потоки данных, сеть/обход блокировок и известные ограничения. Не обходи весь репозиторий заново: открывай только файлы, на которые указывает архитектура.

- Flutter в окружении недоступен, компилятора нет: проверяй импорты/скобки скриптом, а компиляцию — через CI (`gh run list -R vnikolas2009/ysplayer`, сборка ≈ 7 мин).
- Пользователь пишет по-русски; строки интерфейса — на русском.
- Чистую логику — в `lib/core/utils/` + тест в `test/`. Существующие тесты не ломать.
- Коммиты в `main` запускают релизную сборку; сообщения в стиле `feat: ...`.
- При изменении структуры, провайдеров, потока воспроизведения или сети обновляй `ARCHITECTURE.md` (и README, если меняются возможности).
